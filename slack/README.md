# Slack-related actions

Provides some reusable Slack actions.

## Actions

| Name | Description |
| ------ | ----------- |
| [Slack Notify Release (`release`)](release/) | Dispatch a Slack release Notification in a given channel |
| [Slack Test Notification (`test-notify`)](test-notify/) | Post a standard test-run notification (title, body and delivery) to a Slack webhook |
